5-Node Processing
Pipeline

🎂1
Age Check
Validates applicant's age. Minimum 18 years required for eligibility.
🏅2
Experience Rank
Categorizes into Junior / Mid-level / Leader based on years of experience.
📊3
Score Calc
Computes a score from 4–10 based on experience, skills, and achievements.
⚖️4
Decision Node
Conditional routing: score ≥ 6 advances to response; below routes to END.
📨5
Response Gen
Generates the final outcome message and schedules interview for approved candidates.

Tech Stack

🕸
LangGraph
Stateful multi-actor graph framework powering the 5-node agentic pipeline with conditional routing.
🔗
LangChain
Orchestrates LLM integrations and agent tools. Foundation of the processing chain logic.
📝
TypedDict State
Strongly typed shared state object carries all applicant data through every node of the graph.
⚙️
Conditional Edges
Dynamic routing at the decision node routes to interview scheduling or terminates the pipeline.
🐍
Python 3.10+
Core runtime with type hints and async support. Originally prototyped in Google Colab.
🔬
Score Engine
Rule-based scoring assigns 4–10 points combining experience, skills, and achievement signals.
